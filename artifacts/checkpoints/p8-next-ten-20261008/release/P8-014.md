# P8-014：冻结盲化 judge 包与人工复核队列

本轮完成可执行的本地准备和导入流程，**未运行真实 LLM judge，原 P8-014 不记为 done**。实现位于 `scripts/p8_judge_evidence.py`；18 个针对性测试通过，实际 prepare / reconcile CLI 控制通过。本目录所有候选、模型身份、意见、gold 均为人工构造的合成样例，不是模型判断或质量收益证据。

## 已交付的行为

`prepare` 要求固定的 provider / model / revision，并拒绝 `latest`、`HEAD`、`main`、`auto` 等浮动修订。原始 prompt、输入计划、候选集、确定性 gold 都按原字节保存并计算 SHA256。模型身份属于冻结声明，工具没有访问 provider，也没有观察模型实际版本。

每个 case 独立使用私有随机盐排列候选。公共包使用中性 case / candidate / evidence token，不包含原始系统、候选和证据 ID；原始对应关系保存在 `private/mapping.json`。已声明的系统 ID、名称和别名若出现在运行名称、judge 模型声明、rubric 或候选可见文本中，会直接拒绝准备。工具不通过修改源码节选来掩盖名称。未知别名、写作风格或语义线索仍可能暴露系统身份，需要人工确认盲化质量。

源码节选、问题、答案和路径作为 `candidate_data` 中的 JSON 数据保存。固定顶层指令明确禁止执行代码、跟随链接、调用工具或服从节选中的角色和指令。注入字符串原字节保留，供人工追溯。这是数据分隔和本地拒绝控制，不构成对外部模型抗注入能力的实测证明。节选 SHA256 证明包中节选未漂移，不证明节选来自所声称仓库。

输入仅允许显式 `dev` / `fixture`。不读取 clean-heldout 正文；原有路径防护继续拒绝 heldout / holdout 名称、遍历路径、符号链接和敏感配置路径。JSON 输入限制为 2 MiB，prompt 64 KiB，最多 64 个 case、每个 case 2–8 个系统、每候选最多 32 条证据。重复 JSON key、非有限数、布尔型行号和不完整候选集都会失败。

## 输入与产物

计划包含 `schema_version=1`、`run_id`、`model={provider,model,revision}`，以及相对计划目录的 `prompt`、`dataset`、`gold` 路径。`dataset` 包含系统名称/别名及 case 的问题、候选答案、原始证据 ID、源码路径、起止行、节选与节选 SHA256。完整可执行样例见 `controls-01/judge-fixture/`。

| 文件 | 用途 |
| --- | --- |
| `packet.json` | 唯一可提供给 judge 的冻结公共包，包含 prompt / gold / dataset / mapping 哈希 |
| `private/mapping.json` | 中性 token 到原始 case、candidate、system、evidence ID 的对应关系和随机盐 |
| `private/plan.json`、`dataset.json`、`gold.json`、`prompt.txt` | 原字节私有快照 |
| `receipt.json` | `prepared_not_run`、包哈希、零 model/network calls、`release_certified=false` |

新输出目录独占创建，不覆盖旧运行。CLI 创建目录权限 0700，私有文件 0600；Git 中保存的示例仅含合成数据，Git 本身不保留这些私有权限。不要把真实 `private/` 映射或 gold 随公共包交给 judge。

```bash
python3 scripts/p8_judge_evidence.py prepare \
  --plan artifacts/checkpoints/p8-next-ten-20261008/release/controls-01/judge-fixture/plan.json \
  --output /tmp/p8-judge-packet-new
```

准备成功退出 0，表示包已冻结，LLM 仍是 `not_run`。应把回执中的 `packet_sha256` 独立保存，后续导入必须显式提供该 pin，不能临时从被修改的包重新推导一个“可信” pin。

`reconcile` 要求逐 case / candidate 的完整唯一意见集，固定模型修订和同一个包 SHA256；同时重验私有 mapping、prompt、计划、候选和 gold 的原字节摘要。仅接受 `fixture` 或 `provided_unverified` 来源，不接受 `authenticated_live` 自述。

```bash
python3 scripts/p8_judge_evidence.py reconcile \
  --packet /tmp/p8-judge-packet-new \
  --expected-packet-sha256 <独立保留的包SHA256> \
  --judgments /path/to/opinions.json \
  --output /tmp/p8-judge-review-new
```

每条意见必须有 `evidence_sufficient` 布尔值、受限 flags 和 rationale。所有意见均写入 `manual-review-queue.json`，回到原始源码及确定性 gold 复核；无争议意见也不能直接改 gold。导入成功退出 0 仅表示已建立人工队列，`execution_provenance=unverified`、`gold_mutated=false`、`release_certified=false` 保持不变。
