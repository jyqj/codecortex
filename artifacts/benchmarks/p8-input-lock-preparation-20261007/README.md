# P8-001 input-lock preparation (2026-10-07)

**This is groundwork. P8-001 remains `todo`, its P7-020 dependency remains open,
and this checkpoint declares no release candidate or P8 acceptance.**

The new offline tool rejects reuse of a pinned report's inputs after changes to
binary, source, configuration, corpus/query, scoring, model, recorded environment
or complete report-directory membership. It complements existing cc-eval
`InputManifest` and `RunManifest` contracts. It does not replace their loader,
scorer or actual execution and does not authenticate supplied receipts.

product invocation. Repeated functions across source versions are not added into
a larger test total. See [task-receipt.json](task-receipt.json), the individual raw
logs/receipts, and [independent final review](p8-001-independent-final-review.json).

## Rechecking the evidence

```sh
python3 -B artifacts/benchmarks/p8-input-lock-preparation-20261007/verify-evidence.py
python3 -B artifacts/benchmarks/p8-input-lock-preparation-20261007/verify-evidence.py \
  --source-root /path/to/checkout \
  --input-root /path/to/retained-workspace-bundle
python3 -B -m unittest discover -s tests/evidence_lock -v
```

The first command checks stored artifact bytes and receipts. Optional
`--source-root` compares the three exact tool/test/doc inputs, not an entire future
repository. Optional `--input-root` rechecks the concrete prior benchmark inputs.
Its original root was `/workspace/scratch/71bc431c4e4f`; another root is allowed
only with the same selected relative paths and bytes. The actual binary/source/raw
bundle must still be present. Missing external inputs fail closed; a fresh Git
clone alone does not supply the archived executable bytes.

All original logs, reviewer controls and receipts are retained without byte
normalization. `baseline-locker.py.txt` is the exact Git blob from the frozen
regression source. The external lock pin comes from this reviewed checkpoint;
recomputing a pin from an edited lock does not authorize reuse of the original
report. The original acceptance and V01/V02 responsibilities remain in
`docs/roadmap/code-index-v2/tasks.json` and `09-BENCHMARK.md`. Full related regression
and release gates remain with their original owner.
