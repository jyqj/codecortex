# Prospective local 1k origin registration

This is an additional full-matrix study with deterministic execution origins.
It leaves the original G GitHub workflow 37830173594 and its complete
301-artifact receiver unchanged. That original workflow was already running
when this registration was written; this is not described as its initial blind
registration.

Before any local scale measurement, all 150 primary scale/index cells are fixed:
the 30 original 1,000-file cells use one sequential local cohort; the other 120
use their exact original-G GitHub jobs. At registration, a complete two-page
151-job API ledger showed all 30 GitHub 1k jobs queued with no executed steps,
10 larger jobs running, and no measured shard completed. The independent review
checked every one of the 150 plans against the unmodified G registered_plan.

The local source must be a real clean Git checkout of G
`bb9a96d71622458c39a143055360cc97f0d11d78` at the producer's compiled path
`/home/runner/work/codecortex/codecortex`. All 1,087 Cargo/crates inputs and both
original scale observers must equal the retained build. The original GitHub
build receipt and binary are copied without changing their bytes; only the
executable permission of the owned execution copy is restored. This is reuse
of an identified original build, not a claim of a new local compilation.

Original N30, global sample IDs, seed, dirty/resume budgets, all five 1k-owned
fanouts, 15-table exact Value parity, release admission, five-hour native
deadline and 512MiB raw limit remain unchanged. The original run_shard is not
hosted-only and performs the same disk preflight locally. The separate hosted
SDK preparation helper is not invoked or impersonated. Capacity estimates and
observed shared memory headroom do not certify a peak resource bound.

The source, plans and build are checked before the first cell, then the actual
first cell is fully validated with the original functions before the sequential
cohort continues. Any failure, capacity refusal or missing cell leaves this
study failed or incomplete. A failed or slow local cell cannot be replaced by
a successful or faster GitHub duplicate. Additional original GitHub 1k
executions are retained under their true identities outside this preselected
study and never increase its N30 denominator.

Final acceptance still requires all 150 primary directories to pass the
unchanged validate_build, validate_shard/inspect_raw and combine/aggregate,
including all 50 groups and 1,500 measurements. The local CPU, kernel, host and
parallelism are separate environment strata; no heterogeneous pooled timing or
causal speedup is inferred. The complete local cohort alone closes no TODO.

`registration.json` is the authoritative primary-origin map. The registration
code, full original API ledger, feasibility/path contract and non-author reviews
are preserved in `registration-originals.tar.gz`; its manifest records every
original member hash and mode. Publication occurs before local measurement.
