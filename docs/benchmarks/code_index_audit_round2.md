## 成本与预算：生产响应不等于离线适配器

每种延迟模式有 39 次观测。小样本尾分位仅供回归观察，无速度提升或 50K
性能结论。增加诊断和补召回有成本，不能只公布召回收益。

以下严格预算表按 **9 个源码任务等权**计算：完整生产 handler JSON 超过预算
则该请求不获得预算内充分性信用。使用 tiktoken 0.12.0 / cl100k_base 的精确
计数，特殊 token 当普通文本，无额外 chat framing/工具说明固定开销（设为 0）。

| 完整 handler 预算 | #3 基线充分率 | 本轮充分率 |
|---|---:|---:|
| 1K token | 0.333333 | 0.555556 |
| 2K token | 0.555556 | 0.777778 |
| 4K token | 0.666667 | 0.888889 |
| 8K token | 0.777778 | 1.000000 |
| 16K token | 0.777778 | 1.000000 |

独立的 `normalized-source-prefix-v1` **离线适配器**按另一个明确协议打包；

0.857143 → 1.000000。这些数字不是当前 MCP 自动打包效果，也不能与上表
不同权重口径混用。代码仍保留旧 novelty nDCG，但不以其证明跨切块优劣。
