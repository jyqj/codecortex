## Metric definitions and denominators

Profiles stay `codecortex-native-v1` and `oce-compat-v1`; immutable exact base implementation hashes are in authority-locks. Scorer upgrade requires separately reviewed version, both-arm replays and preregistration amendment, never silent reinterpretation.

- **Native answerable:** one primary designation or several true substitute primary groups established from source. top1 accepts any primary group; required facets remain separately required groups. Linear nDCG10 grades1–3. One returned hit greedily consumes the highest-grade unmatched group, ties by source gold group order. Native hits are not path-deduplicated; duplicate evidence gets no second credit for an already matched group. Native match requires exact path, all supplied symbol identity fields, positive span overlap if supplied, and no explicit invalid evidence. Recall5/10 count greedy matched groups / all applicable groups; MRR10 first primary. Retrieval failures receive0, not exclusion. Partial answerable scores may be computed but status/availability is reported separately and prevents a complete quality claim. Recall20 is **not currently implemented** and primary top_k10 cannot certify it.
- **Compat answerable projection:** from reviewed explicit native paths; stable native group order with primary groups first, then supporting groups; flatten alternatives in their frozen source order and retain the first occurrence of each explicit path. Literal paths only, no glob ambiguity. No symbol/span/facet/chain claim; separate paired compat result. Paths deduplicated at first occurrence; Top1Any any expected path, gains2 for first expected and1 for each other, each expectation at most once, nDCG10 fixed linear. Empty expectations are schema error. Compat is not native and does not accept no-answer; no-answer families are excluded from compat with public denominator counts, not encoded with fake expected paths.
- **Native spans:** byte-span coverage uses source bytes, never chunk IDs. Current implementation unions all supplied gold alternative spans per path (including mutually substitutable alternatives), unions valid returned spans per path, then intersection / returned union and intersection / gold union. This is the frozen current formula; alternatives do not select their most favorable gold span. Return evidence on off-gold paths enlarges precision denominator. No gold spans => not_applicable, not1. With gold spans and no valid returned span precision/recall0. Failed rows0 on applicable span metrics. An alternative-conditional span formula is a future version, not changed here. Full facet/span/source-body evidence must be retained for independent replay.
- **Facets:** annotations.v19.facets items `{id,group_id,required:true}` define required evidence roles before retrieval; each required group-id references an actual native answer group. Required-facet coverage intended = fraction whose referenced group's alternative is satisfied under the frozen native match predicate in top10; groups are independent facets and alternatives substitutes. Existing cc-eval does **not expose this metric**, so it stays `not_implemented` until separately reviewed implementation and literal goldens exist. No path-only proxy. Optional facets excluded from denominator; a zero-required-facet query is not_applicable. Ordered graph_constraints are similarly source-reviewed required nodes/edges/directions/types, with no current graph-correctness metric; file hit cannot certify a chain. SymbolAccuracy, DuplicationRate and full freshness also need explicit support, not inferred from top1.
- **No-answer:** only independently source-proven absence under declared scope; native arrays both empty. Denominator = every scheduled eligible no-answer query, including timeouts/cancel/protocol/tool error/Partial. Correct rejection requires normalized status `no_match` and zero hits; Partial empty and every failure are incorrect. Current score() additionally treats Success+empty as correct; preregistered strict no_match accuracy is a **separate status audit**, not a replacement native score. Report both and their discrepancy, block formal correctness claims until envelope semantics are audited; never silently claim the strict rule was the existing scorer. No-answer rows do not enter answerable nDCG/top1 means. No-answer variants average inside family for cluster summary; show individual row count and no-answer-family count. Answerable no_match gets0. Missing scheduled rows make measurement invalid, not silently absent or imputed as accepted no-answer.

For each arm preserve every row/status, repetition index, timestamps/censored deadlines, raw path/hash, normalized hits/spans/body validation, lane statuses, effective budgets/generation/readiness and cost availability. EvidenceValidity has no unknown-as-true policy: explicit invalid source/scope/version is a hard blocker; unknown/unverified is counted and prevents claiming verified evidence. Source leakage0, critical deterministic correctness100%, scorer goldens identical, per authority. These are integrity criteria, not tradeable against aggregate quality.

## Aggregation, paired intervals and margins

Design decision: compute each per-query metric as the arithmetic mean of its3 scheduled repetition scores; repeated requests never multiply N. Report query micro mean over all eligible query variants (transparently counts variants), equal-weight repository macro mean, repository/category cell means and equal-weight category macro mean over nonempty frozen cells. Also report family-balanced means: mean variants within global family, then equal family weight, and within each repo equal-weight family means. Primary quality comparison uses family-balanced repository macro, not a translation-heavy query micro mean. All denominators and missing/unsupported applicability counts accompany each metric; no aggregate includes quarantine. Cross-repo components are single sampling clusters; their repo-specific outcomes stay attached.

Freeze paired candidate-minus-baseline per-query deltas, then mean repeated measurements/variants inside a global-family cluster. Primary95% paired family-cluster percentile bootstrap:10000 replicates, seed20261003, deterministic Python `random.Random(seed)` with ordered sorted keys, nearest-rank quantiles ranksceil(.025*B)-1 andceil(.975*B)-1. Design decision, chosen before ranking; not an existing evaluator capability. For components confined to one repo, resample N_repo clusters with replacement independently within each fixed repository, recompute weighted macro/micro using attached cases. For cross-repo components, group by their exact repository-membership signature, resample original N_signature clusters within each signature and carry **all repo outcomes together**; this preserves pairing/leakage units and repository counts without treating a component as independent per repo. Do not split components to obtain narrower intervals. Report fixed six-repository conditional inference, not generalization to all unseen repositories. Category/exact/semantic subgroup use the same cluster draws with pre-frozen eligibility; empty strata produce not_applicable. Fewer than2 independent eligible components or otherwise degenerate/missing denominators =>inconclusive, not bootstrap-certified pass. Two-arm results missing for scheduled cases invalidate comparison; tool failures with valid rows remain observed0 quality and availability failures. Existing cc-eval bootstrap2000 unstratified family means and compare policy are **different diagnostics**, not this global interval.

All metrics/deltas and intervals are reported, no post-hoc chosen best metric or slice. Primary native quality nDCG10 and PrimaryTop1 are co-primary descriptive outcomes; compat is separate. Semantic/exact family subsets are pre-frozen via source-task categories/tags and reviewer receipt, never inferred from performance. Any exploratory extra slice is labelled exploratory. No hypothesis selection after ranking. No significance claim that ignores multiple inspected slices; any confirmatory multi-arm extension needs preregistered multiplicity handling before execution.

Authority09 §10 suggests absolute nDCG degradation0.01 and PrimaryTop1 one percentage point as **review triggers**, not tolerable correctness errors or automatic acceptance/non-inferiority margins. Freeze those triggers as candidate-minus-baseline mean <-0.01 for each metric; CI crossing a trigger is inconclusive, a reviewer decides next action without changing frozen gold. For performance >10% requires explanation/review, >20% blocks a adequately sampled comparable profile; no latency pass from this quality design (no200-sample tail certification).

**No permissive non-inferiority margin is invented.** Conservative preregistered design choice for a future separately authorized semantic benefit claim: held-out semantic family-balanced nDCG paired95% lower CI>0, and held-out exact family-balanced nDCG and PrimaryTop1 lower CI>=0 (zero tolerated regression in this design), with integrity criteria satisfied. Authority requires semantic gain and no material exact degradation but does not specify this numeric exact bound; zero is explicitly our conservative decision. Current task cannot test these live arms. If unavailable data or CI uncertainty prevents these conditions, status=inconclusive/blocked, never passed. General V19 gate is not automatically decided by these two numerical outcomes: all required corpus, independent review, custody, source/facet/span/availability and reporting obligations remain.
