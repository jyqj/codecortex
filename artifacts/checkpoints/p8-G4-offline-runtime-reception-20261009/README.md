They may contain signed storage redirect URLs and are therefore excluded by five exact upload paths. `withheld-original-job-logs.json` records each original job API reference, presence, byte count and SHA-256, plus a safe typed checkout/exit-event excerpt. The file inventory marks those raw paths as not included in the upload. The excerpts are deliberately incomplete and never replace the raw logs as validator input; complete independent replay requires retrieving the original Actions logs. All five original ZIPs, their complete expanded evidence and every other output are retained in the upload. No raw job log is deleted or edited.

A transfer timeout records a fixed failure containing only the registered API-relative path. The controller does not serialize `TimeoutExpired`, whose original argument list includes the authorization header. Transfers are not retried. These output-safety changes do not alter any of the three original receiver bodies or their predicates.
